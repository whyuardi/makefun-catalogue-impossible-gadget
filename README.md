A catalogue photograph of an impossible gadget: the PERPETUA phone. Its own
charging cable leaves the bottom port, loops around, and plugs back into the
top of the same phone — so it charges itself, forever. Screen reads 100%,
CHARGING ITSELF, no outlet, no end.

Entry for [The Catalogue Photo of an Impossible Gadget](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341) on make.fun.

## Run

```sh
python3 main.py   # writes /output/entry.png (1024x1024, < 1 MiB)
```

The image is drawn entirely in code with Pillow: studio-gradient background,
soft floor shadow and reflection, titanium-framed phone, and the looping cable.
Deterministic, no network.
